## Data marts

Built on the Data Vault model from `img_1.png`. The model has no "group member" link (only `l_chat_owners`),
so group membership is derived from messages: a member is anyone who wrote to the group.

### Analytic marts

1. `dm_user_activity` - per `person_id`: messages sent and received, first and last message date, active days,
   number of groups the person wrote to, number of groups the person owns.
2. `dm_group_activity` - per group: `title`, `status`, owner, group age (from `created_date`), message count,
   distinct authors, last message date, messages per day, "dead group" flag (no messages for N days).
3. `dm_demography` - by `country` and age bucket (from `date_of_birthday`): users, active users,
   average messages per user.
4. `dm_messages_daily` - per day (and hour / weekday from `msg_time`): messages total, private vs group,
   distinct authors (DAU).

### System marts

Source: Airflow metadata DB (PostgreSQL), loaded into Vertica (e.g. schema `stg_airflow`) by a separate DAG.

1. `dm_sys_schedules` - schedule correctness, per DAG:
   - `schedule_interval` / `timetable_description`, CRON validity (`croniter`);
   - `is_paused`, `is_active`, import errors (`import_error`), `next_dagrun`;
   - expected runs for the period by CRON vs actual runs in `dag_run`, missed runs;
   - "expected but not registered" flag: comparison with the reference list of scheduled DAGs.
2. `dm_sys_task_runs` - task run statuses, per `dag_id` / `task_id` (from `dag_run` and `task_instance`):
   - last status, counts of success / failed / up_for_retry / skipped, success rate;
   - average and max duration, retries (`try_number`);
   - last successful and last failed run time;
   - "stuck" flag: running longer than a threshold.
